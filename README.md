# MP2: Data Processing REST API

This project is a FastAPI app that takes CSV datasets, keeps them in memory, and runs them through the data pipeline functions from MP1. A client uploads a CSV with `POST /upload`. It gets back a dataset ID plus the row count, column count, and column names. `GET /datasets/{dataset_id}` returns up to `limit` rows of a stored dataset plus the total row count. `POST /datasets/{dataset_id}/process` validates and cleans a stored dataset from a JSON configuration (required and numeric columns, duplicate removal, missing-value handling, outlier removal). It returns a cleaning report and swaps the stored data for the processed result. `GET /health` gives back the app status and version. The code splits into `main.py` (endpoints), `src/` (models, in-memory storage, logging setup, and request-logging middleware that adds an `X-Request-ID` header to every response), and `data_pipeline/` (the reusable MP1 loading, validation, processing, and output modules). Tests in `tests/` use pytest and TestClient to cover the upload, process-and-retrieve, and missing-dataset workflows. To run the API, use `python -m uvicorn main:app, reload` and open `/docs`. For the tests, use `python -m pytest tests -v`.
